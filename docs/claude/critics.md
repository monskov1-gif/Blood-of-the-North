# Агенты-критики

Правило владельца: «подключи агентов-критиков, которые оценивают скриншоты по шкале 0–10; если оценка
ниже 5–6 — переделывать и улучшать, пока работа их не устроит». Рабочая планка: **ни одной оценки ниже 6**,
цель — 7.

## Цикл

1. Сделать правку → снять скриншоты всех затронутых мест (день и ночь, ключевые точки, крупные планы).
2. Склеить в сетки (PIL), чтобы один критик видел всю локацию: `grid_day.png`, `grid_night.png` и т.п.
3. Запустить критиков параллельно — по одному на тему (например «больница+блик» и «машина+виды»),
   `subagent_type: general-purpose`, в фоне.
4. По ответу: всё, что ниже 7, — разобрать; ниже 6 — обязательно переделать. Сначала исправлять самые
   низкие оценки.
5. Пересъёмка → следующий раунд только по тем темам, что были ниже планки. Повторять до прохода.
6. В отчёте владельцу — таблица «было → стало».

**Перед тем как верить критику — проверить, не артефакт ли теста** (пример: ночной этап начинается с
Джулиана в кровати, и в кадре его «нет»; заставлять его встать в тестовом JS). Пересвет в тестах может
быть завышен из-за принудительного веса окон.

## Шаблон промпта критика

```
You are a strict art director / game-visual critic. Score screenshots of a browser 2.5D pixel-art
narrative game "Blood of the North" (three.js, side-on camera, Russian UI). Setting: <локация, время,
что должно читаться>. <Если раунд N: previous scores were …>

Look at these images with the Read tool:
1. <абсолютный путь> — <что на картинке, слева направо>
2. …

Requirements from the brief: <требования владельца по пунктам>.

Give scores 0–10 for: (a) …, (b) … . For each score below 7, list the 3–5 most important concrete,
actionable fixes (specific elements, positions in the frame, colours, sizes). Be concise
(max ~300 words). Do not edit any files.
```

Для блика всегда прикладывать сравнение с референсом: `docs/claude/flare_reference.jpg` слева,
наш блик на чёрном справа (`tools/shots/flaretest.js`).

## Как снимать

- Сервер: `python3 -m http.server 8765 &` из корня. После перезапуска контейнера — поднять заново
  и проверять время изменения PNG (иначе «новые» скриншоты окажутся старыми).
- `export PWPATH=$(npm root -g)/playwright`.
- `node tools/shots/at.mjs <stage> <out.png> <x> <z> ["<js>"] [w h]` — загрузить этап, поставить
  Джулиана в (x, z), выполнить JS (`g` — игра, `J` — Джулиан), подождать `WAIT` мс (env, по умолч. 2500).
- `node tools/shots/shot.mjs <stage> <prefix> <t1,t2,…>` — кадры этапа в заданные секунды (катсцены, машина).
- `node tools/shots/views.mjs <dir> '<json [[time, view], …]>'` — текстуры видов из окон.
- Блик на чёрном: `WAIT=1500 node tools/shots/at.mjs hospital_day out.png 40 0.3 "$(cat tools/shots/flaretest.js)" 1104 828`.
- Снимать **последовательно**: swiftshader медленный (~3 fps), параллельные запуски не успевают
  дойти до управления игроком (`NOT-READY`).
- Плавные эффекты в тесте не успевают разогнаться — форсировать:
  `"setInterval(() => { for (const z of g.world.windowLights) { const s = g.windowLight.state.get(z); if (s && s.w > 0.05) s.w = Math.max(s.w, 0.97); } }, 100);"`.
- Ночь с Джулианом на ногах:
  `"J.hideLie?.(); J.state='idle'; J.fall=0; J.root.position.y=0; J.pivot.rotation.z=0; J.pivot.visible=true; J.setVisible(true); J.setPose('idle'); g.player.enabled=true;"`.

## История оценок

| Версия | Тема | Оценки по раундам |
|---|---|---|
| 0.08 | спрайты (шея, ходьба) | → 6–7 |
| 0.09 | больница день | 6 → 7 |
| 0.09 | больница ночь | 6 → 5 → 7 |
| 0.09 | блик vs референс | 6 → 7 |
| 0.09 | окна/блик в игре | 4 → 6 |
| 0.09 | полицейская машина | 4 → 5 → 6 |
| 0.09 | виды из окон | 6 → 7 |
| 0.09 | улица | 6 |

- **0.12** (лес Такхини, меню дел, арест): лес днём 6 → 6; сумерки+волк 4.5 → 6 (бревно так и не читалось —
  заменено каменным выступом, Джулиан «пригнут» опусканием спрайта); пещера 5 → 6; арест 4 → 6;
  меню дел 5 → 6–6.5; телефон Лиззи 5.5 → 7. Урок: 3D-бревно из цилиндров у критиков всегда «труба».
- **0.13** (линия Лиззи, реалистичная природа, аудит примитивов): школа 6/6/4/5 → 7/6/5/6 → 7;
  ноябрьский лес 5/6/3/5 → 6/7/4/5 → 6 (сумерки 5 → 5 → 6); пещера 3/5/4/7 → 4/5/4/7 → 5 → 5 → 5 → 6;
  машина 3 → объёмный кузов (без отдельного раунда); больница 4 → 7; участок 5 → 6; улица 5 → 6.
  Уроки: стена-рельеф из вершинного цвета читается как «размытый фон» — фактуру надо запекать в
  текстуру по карте высот со светом; горизонтальные полосы = «обои», нужна косая слоистость и разный
  шаг; нулевые нормали → чёрные блоки от bloom (см. `sanitizeNormals`). Агенты-исполнители по
  отдельным файлам сцен работают параллельно хорошо, но прерываются лимитом — коммитить чаще.
