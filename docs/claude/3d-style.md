# Стиль работы с 3D и визуалом

## Камера и пространство

- Боковой «кукольный» разрез: ось **x** — вдоль локации, **z** — к камере, задняя стена на `BACK`
  (в больнице `BACK = -4`, высота `H = 3.1`, старое крыло `H2 = 3.8`). Ближняя стена срезана.
- Камера: `this.camera = { distance, height, lookHeight, lookZ, fov, minWidth }`, границы —
  `this.bounds = { walk: { areas: [...] }, camera: { minX, maxX } }`. При расширении сцены двигать оба.
- При входе в сцену — `cameraSys.setShot(null)` + `snap()`, иначе камера ползёт из прошлого кадра.

## Пиксельный регистр

- Спрайты: 1 px = 1 см (`PX` в `Character2D`); у кадра может быть `s` (см/px) в мете атласа —
  например лежачие пациенты на сетке 1.5 см.
- Окружение: маленькие canvas-текстуры с `nearest`, 1 тексель ≈ 1 см (`T(key, w, h, draw)` в сценах,
  `canvasTexture(key, w, h, draw, { nearest: true })`). Без гладких градиентов «из фотошопа».
- Виды из окон: `streetTexture(time, view)` + `pixelate(ctx, w, h, k)` (k=3 для видов, 4 для бара) —
  ступенчатые тона с упорядоченным dither.
- Смешение стилей недопустимо: если спрайт нарисован «гладко», упростить палитру (`quantize` в
  `build_sprites.py`, как у `quinn_drive`).

## Сборка сцен

- Статику — батчами: `bx/pl/cy(…)` копят геометрию по материалу, `flushBatches()` в конце `build()`.
  Динамику (то, что меняется по дню/ночи, анимируется, гаснет) — отдельными мешами.
- Материалы: `this.mat(key, params)` (кэш по ключу). Получить уже созданный — `this.mats.cache.get(key)`;
  **никогда** `MaterialLib.get(key)` без params — падает.
- Расширения сцены — модулем-«китом» с установкой методов на прототип (`installExpansion(Scene, deps)`
  в `HospitalExpansion.js`, как `installCustody` для сюжета). Исходную сцену и сюжетные палаты не трогать.
- День/ночь: `setState('day'|'night')`; модули регистрируют переключатели в списке (`this.expNight.push(fn)`).
- Передний план (`foregroundGroups`) — колонны, косяки, тележки у камеры. Они регистрируются в
  SafeZones и гаснут, если закрывают зону. В больнице зоны «julian (walk)» и «julian legs (walk)»
  держат Джулиана видимым при свободной ходьбе.
- **Важно:** при смене `material.transparent` ставить `material.needsUpdate = true` (three.js запекает
  «opaque» в шейдер, иначе «прозрачный» объект рисуется непрозрачным поверх персонажа).

## Свет

- Никогда не пересвечивать в чистый белый: виды из окон с цветом ≤ `#E4DCCC`, аддитивный блик стекла
  ≤ 0.22, экспозиция от окон ограничена в `WindowLight` (≤ 0.42).
- Окна — `windowLights` (зоны WindowLightZone + WindowLensFlareSource) с профилями `PROFILES` A/B/C/D
  (тёплое / холодное / жалюзи / очень сильное). Реакция — плавная по позиции игрока (~1 с), не вспышка.
- Блик объектива (`src/fx/WindowLight.js`): по образцу `docs/claude/flare_reference.jpg` —
  тёплое ядро, ~20 тонких лучей, мягкие коричневые/оливковые шестигранники у источника, красно-голубое
  хроматическое пятно, цепочка точек, зелёная искра с голубой точкой, тонкие радужные дуги вокруг искры,
  зелёный штрих, лёгкая вуаль. Элементы — на оси «источник → центр экрана», раскладка слегка меняется
  при каждом новом проходе. Полный блик только у самого сильного окна; ghosts гаснут у Джулиана;
  блик только когда окно в кадре.
- Ночь — тёмная и тихая, но читаемая: дежурные ночники с тёплыми пятнами, лунные прямоугольники
  окон на полу, за Джулианом следует слабый холодный ключ (`nightKey` в HospitalExpansion).
- Глобусы/лампы не должны «блумить» как окна (эмиссив ~0.4).

## Спрайты (`tools/build_sprites.py`)

- Атлас: `python3 tools/build_sprites.py tools/raw assets/sprites` → `characters.png/.json`.
  Исходники — `tools/raw/raw_<frame>.png`; новый арт от владельца — через `tools/process_art*.py`.
- **Джулиан (с v0.10):** все кадры пальто/халата и лёжа в халате — с листа владельца
  `tools/art/julian_v010.png` (`tools/process_art4.py`), голова на них своя и одинаковая — **ничего не
  пересаживать и не перерисовывать**. Голова нового `jul_idle` (`graft_head`) ставится только на старые
  кадры без перерисовки: `julian_think`, `julian_seat`. Новые листы от владельца — так же: PNG с
  прозрачностью → отдельный `process_art<N>.py` → `build_sprites.py`.
- **Волки** (`tools/process_art5.py`, лист `tools/art/v012/wolves.png`): собираются из частей по образцу
  владельца `docs/claude/wolf_assembly_reference.jpg`. Слои сверху вниз: голова, шерсть груди, передняя
  левая, задняя левая, торс, хвост, передняя правая, задняя правая (= копия задней левой). Положение и
  размер каждой части — в долях торса (`LAYOUT`, замерено по образцу): лапы увеличены ×1.2–1.36.
  В позе «ест» срезается то, что закрывала поднятая голова (иначе верх груди читается как вторая голова).
- Ходьба — 6 фаз (`WALK_BEATS`). С v0.12 кадры шага Джулиана **не растягиваются** к росту idle (растяжка
  nearest-neighbour дублировала строку на шее — «оторванная голова»).

## Конкретные решения по локациям

- **Полицейская машина**: вокруг всё чёрное, город — только в окнах (маска `buildMatte`). Кузов —
  полный силуэт седана в кадре (`BODY_OUTER`: длинный капот и багажник, арки, колёса с колпаками,
  мигалка, ливрея — тёмно-синяя краска с жёлто-синей полосой), салон — вырез `CABIN`.
- **Больница**: x −22…57. 0–21 — исходная (приёмный, коридор, пост, 107, 109), 23–37 — крыло пациентов,
  37 — тяжёлый проём, 37–57 — старое крыло, операционная за стеной (48–55), окно D в торце.
- **Лес Такхини** (`ForestScene`): x −14…46. Земля — value-noise текстура 2 см/тексель (тайл 2.56 м,
  без «шахматки»). Ряд деревьев у тропы редкий (бледные стволы + ёлки), окна на реку у места (x −3.5…10.5)
  и у поляны (19…28.5); дальний берег — стена ёлок; дальние слои — силуэты `ridgeTex`, не `treeTex`
  (тот на большом размере даёт «пиксельный город»). Передний план — только тонкие берёзы (ёлки у камеры
  при затухании дают призрачные треугольники). Ночью — холодный ключ за Джулианом и подсветка скалы
  у пещеры (иначе валуны сливаются в чёрное). Скалы — сплюснутые додекаэдры (`DodecahedronGeometry` + scale), не боксы; большой блок не ставить ближе
  входа в пещеру. Укрытие в сцене с волком — каменный выступ, Джулиан «пригибается» опусканием спрайта
  (`root.position.y = -0.62`), без новых кадров.
- **Лес, состояния Лиззи**: `l1` — день без оцепления (кордон в `siteGroup` скрыт), группа `lizzyGroup`:
  кости/когти/саженец (x −10…−5), туши + вороны (12…17), следы (21…27); `l2` — сумерки, стадо
  (`critter('deer'|'hare')`, `clearHerd()`), олени `setPose('stand'|'graze'|'dead')`. Зайцы — только `night`/`l2`.
- **Школа** (`SchoolScene`): коридор со шкафчиками, окна на улицу (`streetTexture('day','bar')`), доска
  объявлений, витрина кубков, колонна на переднем плане — в SafeZones (иначе закрывает Лиззи).
- **Пещера** (`CaveScene`): x −18…22: ритуальная −18…−10 (плита −14), зал −10…−2, ниша Лиззи −2…6,
  кладовая 6…11, ниша Пуриэль ≈13, выход 15…22. Состояния `l3/l4/l5` задают границы ходьбы/камеры,
  костры и свет; факелы обязательны (без них hemi 0.7 даёт чёрный экран). Кровь — `addBlood/clearBlood`.
- **Меню дел** (`css/cases.css`): размеры от ширины доски `--W`; нити рисуются по фактическим
  позициям булавок (`linkPins`), а не по процентам.
- **Осень**: поздняя, первый тонкий снег; берёзы/осины полуголые, листья в основном жёлтые + доля
  красно-оранжевых; снег — тонкими корками, не «подушками».

## Производительность

- `?quality=low` — меньше частиц, без отражений пола, блик на половинном разрешении.
- Не дёргать WebAudio-автоматизацию каждый кадр (порог изменения, как в `updateHospitalSound`).
- Блик рисуется готовыми спрайтами (canvas создаётся один раз), оверлей скрыт, когда блика нет.

## Риг по частям (заготовка под анимацию)

- `tools/rig_julian_coat.py` → `tools/art/rig/julian_coat/`: Джулиан в пальто, разрезанный на части
  (head, scarf, torso, arm_near, arm_far, coat_front, coat_back, leg_near, leg_far) — hi-res PNG,
  `px/` — в сетке игры, `rig.json` (смещение, точка вращения, родитель, z-порядок), `overview.png`.
- Скрытые места частей залиты плоским основным цветом самой части (только там, где их закрывает
  более близкая часть); дальняя рука — затемнённая копия ближней. В игру пока не подключено.
