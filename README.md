# Blood of the North — демо (пролог) · v0.04

Визуальная новелла / narrative adventure. Демо «Северная Роза»: бар на окраине
Уайтхорса (Юкон). 3D-окружение + полностью 2D-персонажи с глубиной, исследование,
диалоги в режиме визуальной новеллы, коктейль от незнакомца, галлюцинации и обморок —
а затем утро в том же баре: место массового убийства, тело Кайдена, приезд полиции.

Игра работает прямо в браузере (компьютер, телефон, планшет), без сборки и без
серверной части — это статический сайт.

## Как открыть по ссылке (GitHub Pages)

1. Репозиторий → **Settings → Pages**.
2. **Source:** `Deploy from a branch`.
3. **Branch:** ветка с игрой (`main` после слияния, или текущая рабочая ветка), папка `/ (root)` → **Save**.
4. Через 1–2 минуты игра будет доступна по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Локально: из корня репозитория `python3 -m http.server 8000` → <http://localhost:8000>.
(Открыть `index.html` двойным кликом нельзя — браузер блокирует ES-модули с `file://`.)

## Управление

| Действие | Клавиатура | Телефон / планшет |
|---|---|---|
| Ходьба | A/D или ←/→ | джойстик слева |
| Глубина (ближе/дальше) | W/S или ↑/↓ | джойстик вверх/вниз |
| Быстрее | Shift | кнопка «БЕГ» |
| Осмотреть / говорить / далее | E, Пробел, Enter | кнопка «ДЕЙСТВИЕ», тап по экрану |
| Телефон Джулиана | Q | иконка телефона |
| Меню / пауза | Esc | иконка меню |
| Пропуск прочитанных реплик | удерживать Ctrl | кнопка «ПРОПУСК» |
| Выбор ответа | 1–4 или мышь | тап |

На телефоне лучше держать экран горизонтально. В настройках есть качество графики,
громкость, скорость текста, сила визуальных эффектов и принудительное включение
сенсорного управления (удобно для тестов на планшете с клавиатурой).

Параметры URL для тестирования: `?quality=low` / `?quality=high`.

## Версия

Текущая версия демо — в `src/version.js` (показывается в главном меню, паузе, на экране загрузки

src/ui/                  HUD, экран диалогов (VN), меню, телефон, финал, сенсорное управление

### Утро: BAR_MORNING_CRIME_SCENE

Утро — не новая локация, а состояние того же бара:

* `src/world/scenes/BarMorning.js` — `applyLightingState(bar, 'evening' | 'morning')`: гасит практические
  источники (люстры, свечи, гирлянды, неон), включает холодный дневной свет из окна и открытой двери,
  меняет вид за окном; `buildMorningProps` — опрокинутая мебель, осколки, сумка, следы волочения;
  полицейские мигалки.
* `src/characters/CharacterState.js` — `ALIVE / DEAD / INJURED / UNCONSCIOUS / HIDDEN`;
  `Character2D.setLife(DEAD, { pose: 'lying' | 'slumped' })` — тот же спрайт с шейдерным вариантом
  «труп» (без цвета, бледный, холодный), без idle-анимации, с проколами на шее.
* `data/morning.js` — где лежат тела (те же NPC, что были вечером) и Кайден.
* `src/story/MorningSequence.js` — пробуждение, сцена с Кайденом (`kaydenDeathDiscovered`, один раз),
  вспышка памяти, `POLICE_ARRIVAL`, финальный кадр.
* `data/dialogue/morning.js` — реплики утра.

### Как расширять

* **Новая локация** — класс мира (как `BarScene`) + сценарий (как `BarStory`), регистрация в
  `src/world/scenes/index.js`, диалоги в `data/dialogue/<локация>.js` и в `data/dialogue/index.js`.
* **Диалоги** — только данные: `speaker`, `text`, `expr` (эмоция портрета), `pose` (поза спрайта),
  `if`/`set` (флаги), `choices`, `cmd` (команда режиссёра), `checkpoint`, `distort`.
* **Флаги** — `state.set('noticed_owen')`, условия вида `"read_news && !asked_waiter"`.
  Уже используются: `met_kayden`, `noticed_owen`, `mirror_anomaly`, `read_news`,
  `read_newspaper`, `heard_voicemail`, `asked_about_lizzie`, `trust_kayden`, `drank_cocktail`…
* **Звук** — `src/audio/sounds.js`: у каждого ключа есть процедурный плейсхолдер; чтобы
  подключить настоящий файл, добавьте `url: 'assets/audio/…ogg'` — код сцены не меняется.
* **Спрайты** — `python3 tools/build_sprites.py tools/raw assets/sprites` пересобирает атлас
  (сидячие позы, шаги, перекраски NPC генерируются автоматически).
* **Портреты** — файлы `assets/portraits/<id>_<0|1|2>.webp`; выбор кадра — `DialogueView.drawSlot`.
* **Толпа** — `data/crowd.js`: кто, где сидит/стоит, куда смотрит.
* **Новый арт** — `python3 tools/process_art.py <папка с листами> .` вырезает фон, делает портреты
  и пиксельные спрайты (1 px = 1 см), затем `build_sprites.py` пересобирает атлас.

Окружение, текстуры, фоны диалогов, иллюстрация коктейля и весь звук генерируются кодом; персонажи и портреты — из предоставленного арта.
