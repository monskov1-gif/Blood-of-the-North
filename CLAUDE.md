# Blood of the North — инструкции для Claude

Браузерная 2.5D пиксель-арт новелла (three.js, статический сайт без сборки, русский интерфейс).
Владелец пишет по-русски — отвечать по-русски, коротко и по делу, без лишних вопросов.

## Прочитать перед работой (по порядку)

1. `docs/claude/workflow.md` — как работать с владельцем: темп, автономность, формат отчётов,
   что он ценит и что уже отвергал. **Главное правило — не переспрашивать то, что тут уже решено.**
2. `docs/claude/project.md` — о самой игре: сюжет, этапы, сцены, персонажи, карта файлов,
   текущее состояние и открытые задачи.
3. `docs/claude/3d-style.md` — как строятся сцены, материалы, свет, спрайты, эффекты; визуальные
   правила, которые владелец уже закрепил.
4. `docs/claude/critics.md` — цикл агентов-критиков для любой визуальной правки (оценка 0–10,
   переделывать, пока есть оценка ниже 6).
5. `docs/claude/release.md` — повышение версии и публикация на сайт.

## Постоянные правила владельца

1. **Каждую новую версию публиковать на сайт без вопросов** (`docs/claude/release.md`).
2. **Визуальные правки — только через критиков** (`docs/claude/critics.md`).
3. Голова и шея Джулиана — только пиксель-в-пиксель копия оригинальных нарисованных кадров
   (`3d-style.md` → «Спрайты»). Любую «улучшенную» или сгенерированную голову владелец отвергает.
4. Палаты 107/109 и все скриптовые события должны работать после любого расширения сцен.
5. Каждая правка кода поднимает версию на 0.01; коммит → пуш в рабочую ветку → публикация.

## Быстрый старт

```bash
python3 -m http.server 8765 &            # из корня репо; НЕ `pkill -f http.server` — убивает шелл
export PWPATH=$(npm root -g)/playwright  # Chromium предустановлен; НЕ запускать `playwright install`
node tools/shots/at.mjs hospital_day /tmp/x.png 44 0.6           # этап, файл, x и z Джулиана [, js] [, w, h]
node tools/shots/shot.mjs car /tmp/car 9,15                      # этап, префикс, секунды
node tools/shots/views.mjs /tmp '[["morning","ward107"]]'        # текстуры видов из окон
python3 tools/build_sprites.py tools/raw assets/sprites           # пересобрать атлас спрайтов
node --check --input-type=module < file.js                       # проверка синтаксиса
```

Подробности по скриншотам — `docs/claude/critics.md` → «Как снимать».
