# furniture-kit — Claude Code skill

Drop this folder into another project as `.claude/skills/furniture-kit/` (Claude Code picks the skill
up from `SKILL.md`), or just attach the files to a chat and say: "read SKILL.md and use the kit".

`preview.png` — the demo room (`example-room.js`) in the evening state. Open `preview.html` through
any static server to look around (drag / wheel, buttons for evening / night / day).
